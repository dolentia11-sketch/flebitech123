# Hustler — Juan Pablo · Días 1–2

Insumos de negocio, usuario y sector para el Reto 02 (Venta Automatizada de Seguros).
Todo con fuentes citadas por afirmación y lo no-verificado marcado explícitamente.
Cada documento declara el modelo de IA y esfuerzo con el que se construyó.

## Empieza por aquí

**`pitch/2026-07-22_avances-jara.html`** — abrir en el navegador. Es el reporte
navegable con todo el trabajo en 7 pestañas (resumen, base de afiliados, catálogo,
mapa segmento→producto, limitaciones de la data, propuesta de marketplace,
investigación del sector). Todos los entregables son clickeables desde ahí
(versiones legibles en `pitch/docs/`).
